# UI Density Refinement

Tightened vertical spacing and element sizes across key journey components.

## Changes

### 1. Course Detail (Quest Journey)
- Header margin: `mb-8` → `mb-4`
- Progress bar container: `pt-6 pb-12` → `pt-2 pb-8`
- Runner indicator: `w-10 h-10` → `w-8 h-8`, border `4px` → `3px`
- Stats row: `mt-6 py-6` → `mt-2 py-3`

### 2. Roadmap (Progress Header)
- Card padding: `p-8` → `p-5`
- Card margin: `mb-8` → `mb-5`
- Section gap: `gap-8` → `gap-4`
- Vertical dividers: `h-16` → `h-12`

## Rationale
User reported "too big" spacing compared to subsequent sections. These changes align the density with the rest of the application.
